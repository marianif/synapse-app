# Week 1 (W21): May 22 – May 24, 2026 — Installing the Mirror

A plugin gets installed so the app can be shown to itself for the first time.

## Narrative

It starts, fittingly, with friction. On May 22 at 8:15 PM, Federica tries four times in a row to install a plugin called impeccable-native from a local directory (`/Users/federicamariani/Desktop/impeccable-native`), tripping over Claude Code's slash-command marketplace mechanics along the way — S153 through S158 are a compressed loop of "add to marketplace," "no wait, install," "why isn't this recognized," "let me explain again." By 8:24 PM the plugin is verified, its directory structure and manifest format understood, and its skill installed locally. Twenty minutes of setup friction, then it works.

What impeccable-native turns out to be is a mirror. Pointed at synapse-app, it immediately produces a design critique of the calendar screen: 25/40, with two P0 accessibility violations. This is the week's sharpest beat — a tool the user just fought to install turns around and grades the house. The next day, May 23, the plugin runs its "flow" mapping again (Expo Router: 6 screens, 2 navigators, 22 transitions) and gets its first proper status-assessment session, checking navigation mapping and Watch integration progress against a roadmap that doesn't fully exist yet. In the same session, two features that clearly predate this recorded window surface as facts to be catalogued rather than built: Apple Watch bidirectional sync with voice capture, already complete, and a date-handling refactor already merged.

May 24 opens with impeccable-native's "teach" command formalizing what's been observed — a name for the design system, "The Kinetic Equilibrium," and a product-strategy decision logged at 12:06 AM. By 12:28 AM the session pivots to housekeeping: initializing CLAUDE.md itself, so the next agent won't have to rediscover any of this by hand.
